# GitHub Pages 배포용 모아 프로토타입

이 사이트는 운영자가 요청해 실제 매출·지출 거래내역을 공개하고 있습니다. 거래일, 대관자, 경로, 금액, 지출 항목과 내용은 누구나 볼 수 있습니다.

## 배포 전 확인

- 저장소와 사이트는 공개 상태입니다. 거래자료가 GitHub 변경 기록에 남을 수 있으며, 나중에 파일을 삭제해도 기존 기록은 남을 수 있습니다.
- 방문자가 등록한 데이터는 각 브라우저의 로컬 저장소에 저장되며, 여러 기기나 사용자 간에 자동 동기화되지 않습니다.
- Excel 파일 읽기는 SheetJS CDN을 사용하므로 인터넷 연결이 필요합니다. CSV 파일은 브라우저에서 처리합니다.
- 사이트에서 추가로 입력하는 내역은 해당 브라우저의 로컬 저장소에 보관되고 저장소에는 자동으로 올라가지 않습니다.

## Pages 설정

1. 공개 저장소 이름을 `theldancehall.github.io`로 만듭니다.
2. 이 폴더의 파일을 저장소 루트에 올립니다.
3. 포함된 GitHub Actions 워크플로가 main 브랜치에 올라오면 Pages 배포를 시작합니다.
4. 배포 완료 후 https://theldancehall.github.io/ 에서 확인합니다.

배포 저장소는 `theldancehall/theldancehall.github.io`입니다.
